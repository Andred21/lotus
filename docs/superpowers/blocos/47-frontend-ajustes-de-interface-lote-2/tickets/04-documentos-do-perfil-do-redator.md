# 04: Documentos do Perfil do redator logado no padrão do slot

**What to build:** no Perfil do redator logado, os documentos (Currículo, Título, Pós-graduação e o
REUF, que é só leitura) usam a peça compartilhada. O botão de texto "Substituir"/"Enviar" vira o
ícone do slot, com dica. A tag de estado ("Vence em…") e o aviso de documento gerido pela
administração continuam. Não há excluir: o backend não o oferece ao próprio redator.
